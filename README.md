# Eashika Ashubod — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and sections
- `style.css` — responsive layout and visual styles
- `script.js` — mobile navigation and current footer year

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the website.

For a custom domain such as `ashubod.me`, configure the domain in **Settings → Pages** and update the DNS records at your domain provider according to the instructions GitHub shows.

## Personalize before publishing

- Replace `hello@ashubod.me` with the email address you want to share.
- Replace the generic LinkedIn and Instagram profile links with your own profile URLs.
- Add real project screenshots, outcomes, and your precise role in each project.
- Review every project description and only keep claims that accurately describe your contribution.
- Add your own profile photo if you want a more personal introduction.
